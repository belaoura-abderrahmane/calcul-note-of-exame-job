# برنامج حساب نقاط مسابقات التوظيف على أساس الشهادة (الوظيف العمومي)

تطبيق **Laravel 13 + Filament 5** بواجهة عربية (RTL) لحساب وترتيب نقاط المترشحين من **30 نقطة**.

## المعايير السبعة

| المعيار | الحد الأقصى | طريقة الحساب (القيم الافتراضية) |
|---|---|---|
| مطابقة التخصص | 6 | تُدخلها اللجنة مباشرة (0 → 6) |
| المسار الدراسي | 7 | سلم المعدل (10.50→1 … 16→7) + علاوة تقدير الماستر + علاوة المدرسة العليا / الأول على الدفعة، والمجموع لا يتجاوز 7 |
| التكوين التكميلي | 2 | 0.5 لكل تكوين |
| البحث العلمي | 1 | 0.5 لكل عمل منجز |
| الخبرة المهنية | 6 | **لا تُجمع الأنواع**؛ يُعتمد النوع الأكثر نقاطاً: نفس المؤسسة 1/سنة، جهاز الإدماج 1/سنة، إدارة عمومية أخرى 0.5/سنة، القطاع الخاص 0.25/سنة (الأشهر تُحتسب كجزء من السنة) |
| أقدمية الشهادة | 5 | 0.5 عن كل سنة كاملة بين تاريخ الشهادة والتاريخ المرجعي للمسابقة |
| المقابلة الشفهية | 3 | تُدخلها اللجنة |

> ⚠️ علاوات تقدير الماستر، علاوة المدرسة العليا / الأول على الدفعة، ونقاط التكوين والبحث وأنواع الخبرة هي **قيم افتراضية قابلة للتعديل** من صفحة **«إعدادات التنقيط»**. تحقق منها وفق النص التنظيمي المعمول به لديكم، ثم احفظ: يعاد حساب نقاط جميع المترشحين تلقائياً.

## الصفحات

- **لوحة التحكم**: إحصائيات، توزيع المترشحين حسب المجموع، متوسط كل معيار، أفضل المترشحين.
- **المسابقات**: إنشاء مسابقة (الرتبة، عدد المناصب، التاريخ المرجعي…)، عرض الترتيب، طباعة محضر الترتيب، إعادة الحساب.
- **المترشحون**: ملف المترشح مع **حساب مباشر للنقاط** أثناء الإدخال، وجدول الترتيب (ناجح / قائمة الانتظار / غير ناجح). عند تساوي النقاط يُقدَّم الأكبر سناً.
- **الحاسبة السريعة**: حساب فوري للنقاط دون حفظ (مثل حاسبة منصة حسابات).
- **إعدادات التنقيط**: تعديل سلم التنقيط كاملاً.
- **طباعة محضر الترتيب**: صفحة جاهزة للطباعة A4 أفقي.

## التثبيت على Laragon (Windows)

المتطلبات: **PHP 8.3 أو أحدث** مع الإضافات `intl` و `zip` مفعلة (Laragon ← PHP ← Extensions)، Composer، MySQL.

1. فك الضغط داخل `C:\laragon\www\calcul note of exame job`
2. شغّل Laragon واضغط **Start All**
3. انقر مرتين على **`install.bat`** (أجب `yes` إذا سُئلت عن إنشاء قاعدة البيانات `calcul_note_exam`)
4. انقر مرتين على **`run.bat`** ← يفتح المتصفح على `http://127.0.0.1:8000/admin`

**الدخول:** `admin@admin.com` / `password` (غيّرها من الملف الشخصي بعد أول دخول).

أو يدوياً من Terminal الخاص بـ Laragon:

```bash
cd "C:\laragon\www\calcul note of exame job"
copy .env.example .env
composer install
php artisan key:generate
php artisan migrate --seed
php artisan serve
```

> ملاحظة: اسم المجلد يحتوي على مسافات، لذلك لا يستطيع Laragon إنشاء رابط `xxx.test` تلقائياً. استعمل `run.bat`، أو أعد تسمية المجلد إلى `calcul-note-of-exame-job` ليصبح الرابط `http://calcul-note-of-exame-job.test/admin`.

## ملفات مهمة

- `app/Services/ScoreCalculator.php` — محرك الحساب
- `config/scoring.php` — القيم الافتراضية لسلم التنقيط
- `app/Filament/` — صفحات وموارد لوحة التحكم
- `tests/` — اختبارات الحساب والصفحات (`php artisan test`)

## نسخة سطح المكتب (ملف exe واحد)

`CalculNote.exe` ملف واحد يحتوي على كل شيء (PHP 8.5 + البرنامج + قاعدة بيانات SQLite)، ولا يحتاج Laragon ولا MySQL ولا إنترنت.

- انسخه إلى أي جهاز Windows 10/11 (64 بت) وانقر عليه مرتين.
- أول تشغيل يستغرق دقيقة تقريباً (فك الملفات في `%LOCALAPPDATA%\CalculNote`)، ثم يصبح سريعاً.
- يفتح البرنامج في نافذة مستقلة (عبر Microsoft Edge المثبت في ويندوز)، والدخول تلقائي.
- **البيانات** تُحفظ في مجلد `CalculNote-Data` بجانب ملف exe. لنقل البرنامج مع بياناته إلى جهاز آخر انسخ الملف والمجلد معاً. (احتفظ بنسخة احتياطية من هذا المجلد.)
- عند إغلاق النافذة يتوقف البرنامج تلقائياً.
- قد يظهر تحذير Windows SmartScreen لأن الملف غير موقّع رقمياً: «مزيد من المعلومات» ← «تشغيل على أي حال».
- في حالة خطأ: سجل التشغيل في `%LOCALAPPDATA%\CalculNote\launcher.log`.

إعادة البناء (على لينكس): `bash desktop/build.sh <مجلد PHP لويندوز> dist/CalculNote.exe`
